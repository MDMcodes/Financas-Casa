    Categorias cadastradas

      Backup dos seus dados

      Tudo fica salvo só neste navegador. Se limpar o cache, trocar de celular ou desinstalar o app, os lançamentos somem. Exporte um arquivo de backup de vez em quando e guarde em algum lugar seguro (Google Drive, e-mail, WhatsApp pra você mesmo) — depois é só importar de volta se precisar.

      Google Drive

      Conecte sua conta do Google Drive pra salvar os lançamentos automaticamente na nuvem, sem precisar exportar/importar manualmente. Isso exige um Client ID do Google Cloud configurado pra esta URL — veja o passo a passo que te expliquei.

      Não conectado.

      Os dados ficam salvos apenas neste navegador (localStorage) — não são enviados para nenhum servidor. Use "Exportar backup" em Categorias para guardar uma cópia de segurança.
